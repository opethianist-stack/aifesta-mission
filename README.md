# aifesta-mission

AI Festa 26 참관 미션 웹앱. 교장 3기 3일차(2026. 10. 8.(목) 13:00~15:00, 코엑스 3층 C홀).

- 10개 특별관 스탬프
- 관별 기록: 들른 부스(칩 선택·직접 추가), 학교 적용 가능성 상·중·하, 교장용 질문 1개 메모
- 마무리 문항 3개 → 성명·소속교로 제출
- 모든 입력은 기기(localStorage)에 즉시 저장되어 통신 두절·이탈 후에도 복구된다
- 제출 완료 화면과 하단 바에 집결 안내(14:50 C홀 입구, 15:00 버스 출발)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 본체. 단일 파일, 외부 의존성 없음(시스템 폰트) |
| `floorplan.jpg` | 브로슈어 2026 Floor Plan 발췌. 안내의 「전시장 배치도」에 나온다 |
| `Code.gs` | 제출 수신용 Google Apps Script. `제출` 탭에 한 줄씩 쌓이고, `현황` 탭이 집계·미제출자를 보여 준다 |

## 배포

1. 구글 시트 「AI페스타 참관미션 제출」을 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다.
2. 편집기에서 `setup` 함수를 한 번 실행한다 → `제출`·`현황`·`명단` 탭 생성.
3. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**. 코드 수정 시에는 `배포 관리 → 편집 → 새 버전`(URL 유지).
4. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다.
5. Vercel에서 이 레포를 Import(프레임워크 Other, 빌드 없음) → `aifesta-mission.vercel.app`.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `INFO` — 연수명, 기수, 일자, 장소, 관람 시간, 집결 지점, 버스 시각
- `CONTACT_ORG`, `CONTACTS` — 문의처. 안내 상자와 제출 완료 화면에 전화·링크 버튼으로 나온다
- `HALLS[].loc` — 플로어맵 위치 힌트(예: "C홀 입구 왼쪽"). 비우면 표시 안 함
- `HALLS[].b` — 관별 부스 칩 목록

## 제출 데이터 열

제출시각, 기수, 성명, 소속교, 스탬프, 전체 관, 부스 수, 들른 부스, 학교 적용 가능성, 관별 메모, 가져갈 기술 1~3, 교직원에게 한 문장, 1년 내 들어올 기술·이유, 기기, 관람한 관(코드), 적용 가능성(코드)

코드 열은 `현황` 탭 집계용이다(`[07]`, `[07상]` 형식).

## 현황 탭

- 제출 인원(성명 기준 중복 제외), 총 제출 건수, 미제출 인원, 마지막 제출 시각, 평균 스탬프·부스 수
- 특별관별 관람 수와 적용 가능성 상·중·하 분포
- `명단` 탭 A열 성명, B열 소속교를 붙여넣으면 미제출자 목록이 나온다(성명 기준 대조)

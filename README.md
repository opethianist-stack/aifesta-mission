# aifesta-mission

AI Festa 26 참관 미션 웹앱. 교장 3기 3일차(2026. 10. 8.(목) 13:00~15:00, 코엑스 3층 C홀).

- 10개 특별관 스탬프 + 피지컬 존(A·B·C존)·멀티클라우드관·스폰서 구역(MC-01 메가존클라우드, M-01 화웨이, M-02 KT) 기록
- 추천 동선(입구 → 출구, 누르면 해당 관으로 이동), 배치도와 검색되는 전체 부스 목록
- 관별 기록: 방문 부스(공식 배치도 부스 번호·기업명 칩, 직접 추가 가능), 학교 적용가능성 상·중·하(선택), 교장용 질문 1개 메모
- 마무리 문항 3개(적용해보고 싶은 기술 1가지 이상, 교직원에게 한 문장, 1년 내 들어올 기술·이유) → 성명·소속교로 제출
- 같은 기기에서 다시 제출하면 시트의 기존 행을 덮어쓴다(제출ID 기준)
- 모든 입력은 기기(localStorage)에 즉시 저장되어 통신 두절·이탈 후에도 복구된다
- 제출 완료 화면과 하단 바에 집결 안내(14:50 C홀 입구, 15:00 버스 출발)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 본체. 단일 파일, 외부 의존성 없음(시스템 폰트) |
| `aifesta26-brochure.pdf` | 행사 브로슈어. 「전시장 배치도 · 부스 찾기」의 받기 버튼으로 내려받는다 |
| `boothmap.jpg` | 공식 홈페이지 부스 배치도. 안내의 「전시장 배치도」에 나온다 |
| `Code.gs` | 제출 수신용 Google Apps Script. 앱이 보내는 항목대로 `제출` 탭 열을 맞추고, `현황` 탭이 집계·미제출자를 보여 준다 |

## 배포

1. 구글 시트 「AI페스타 참관미션 제출」을 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다.
2. 편집기에서 `setup` 함수를 한 번 실행한다 → `제출`·`현황`·`명단` 탭 생성.
3. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**. 코드 수정 시에는 `배포 관리 → 편집 → 새 버전`(URL 유지).
4. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다.
5. Vercel에서 이 레포를 Import(프레임워크 Other, 빌드 없음) → `aifesta-mission.vercel.app`.

## 수정할 때

- 문구·부스·위치·연락처·문항: `index.html`만 고치면 된다. Apps Script 재배포가 필요 없다.
- 시트 열은 `index.html`의 `FIELDS`가 정한다. 새 항목은 시트 오른쪽에 열로 자동 추가되고, 이름을 바꾸면 머리행만 바뀐다. 키는 바꾸지 않는다.
- 특별관 목록(`HALLS`)이나 열이 바뀌면 다음 제출 때 `현황` 탭이 자동으로 다시 만들어진다.
- 각 열의 키는 `제출` 탭 머리행 셀 메모에 있다. 메모를 지우거나 열 순서를 손으로 바꾸지 않는다.
- `Code.gs`는 제출 처리 방식 자체를 바꿀 때만 다시 붙여넣고 재배포한다.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `INFO` — 연수명, 기수, 일자, 장소, 관람 시간, 집결 지점, 버스 시각
- `CONTACTS` — 인솔자·사무국 연락처. 안내 상자와 제출 완료 화면에 전화·링크 버튼으로 나온다
- `HALLS[].loc` — 배치도 위치 힌트. 비우면 표시 안 함
- `HALLS[].b` — 관별 부스 칩 목록("부스번호 기업명"). `z`·`c`는 배치도 구역 코드·색, `g:1`은 피지컬 존, `g:2`는 멀티클라우드관·스폰서 구역(둘 다 스탬프 개수 제외)
- `ROUTE` — 추천 동선(HALLS 순번)
- `FIELDS` — 시트 열 [키, 머리행 이름]

## 제출 데이터 열

제출시각(최종), 기수, 성명, 소속교, 스탬프, 전체 관, 방문 부스 수, 방문 부스, 학교 적용가능성, 관별 메모, 가져갈 기술, 교직원에게 한 문장, 1년 내 들어올 기술·이유, 기기, 관람한 관(코드), 적용가능성(코드), 제출ID, 제출 횟수

코드 열은 `현황` 탭 집계용이다(`[07]`, `[07상]` 형식).

## 현황 탭

- 제출 인원(성명 기준 중복 제외), 제출 행 수(기기 기준), 미제출 인원, 마지막 제출 시각, 평균 스탬프·방문 부스 수
- 특별관별 관람 수와 적용가능성 상·중·하 분포
- `명단` 탭 A열 성명, B열 소속교를 붙여넣으면 미제출자 목록이 나온다(성명 기준 대조)

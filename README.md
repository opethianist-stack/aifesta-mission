# aifesta-mission

AI Festa 26 참관 미션 웹앱. 교장 3기 3일차(2026. 10. 8.(목) 13:00~15:00, 코엑스 3층 C홀).

- 10개 특별관 스탬프
- 관별 기록: 들른 부스(칩 선택·직접 추가), 학교 적용 가능성 상·중·하, 교장용 질문 1개 메모
- 마무리 문항 3개 → 성명·소속교로 제출
- 모든 입력은 기기(localStorage)에 즉시 저장되어 통신 두절·이탈 후에도 복구된다
- 제출 완료 화면과 하단 바에 집결 안내(14:50 C홀 입구, 15:00 버스 출발)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 본체. 단일 파일, 외부 의존성 없음(시스템 폰트) |
| `floorplan.jpg` | 브로슈어 2026 Floor Plan 발췌. 안내의 「전시장 배치도」에 나온다 |
| `Code.gs` | 제출 수신용 Google Apps Script. 시트 `제출` 탭에 한 줄씩 쌓인다 |

## 배포

1. 구글 시트 「AI페스타 참관미션 제출」을 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다.
2. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**.
3. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다.
4. Vercel에서 이 레포를 Import(프레임워크 Other, 빌드 없음) → `aifesta-mission.vercel.app`.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `INFO` — 연수명, 기수, 일자, 장소, 관람 시간, 집결 지점, 버스 시각
- `CONTACTS` — 운영진·비상 연락처. 채우면 안내 상자에 전화 링크로 나온다
- `HALLS[].loc` — 플로어맵 위치 힌트(예: "C홀 입구 왼쪽"). 비우면 표시 안 함
- `HALLS[].b` — 관별 부스 칩 목록

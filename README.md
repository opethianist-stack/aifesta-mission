# aifesta-mission

AI FESTA 26(2026. 10. 6.~8., 코엑스 3층 C홀) 관람용 미션 웹앱. 10개 특별관 스탬프, 관별 질문 메모, 들른 부스 기록, 제출 폼으로 구성된다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 본체. 단일 파일, 외부 의존성은 Pretendard 웹폰트뿐 |
| `Code.gs` | 제출 수신용 Google Apps Script. 시트 `제출` 탭에 한 줄씩 쌓인다 |

## 배포 절차

1. 구글 시트를 새로 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다.
2. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**로 배포한다.
3. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다.
4. GitHub `Settings → Pages`에서 `main` 브랜치 루트를 소스로 지정한다.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `BATCH` — 기수 목록. `?gi=1`로 열면 해당 기수가 자동 선택되고 상단 태그에 표시된다
- `HALLS[].b` — 관별 부스 칩 목록. 배치도의 부스명을 여기에 추가하면 칩으로 나온다. 목록에 없는 부스는 참가자가 현장에서 직접 추가할 수 있다

## 제출 데이터 열

제출시각, 기수, 성명, 소속교, 학교급, 인상 깊은 특별관, 학교 경영에 가져갈 것, 스탬프, 전체 관, 부스 수, 들른 부스(관별 줄바꿈), 관별 메모, 기기

# aiot-mission

AIoT 국제전시회 2026 참관 미션 웹앱. 교장 5기(2026. 11. 5.(목) 13:00~15:00, 코엑스 3층 D홀). `aifesta-mission`과 같은 구조이며 디자인은 네이버 톤(흰 바탕, NAVER Green `#03C75A`, 시스템 폰트)이다.

- 8개 전시 분야 스탬프: 산업·생활 안전 / 스마트홈·오피스·헬스케어 / 에너지·환경·디지털 트윈 / 제조·농림축산·물류 / AI 기술·AI 인프라 / IoT 디바이스·플랫폼 / 유무선 통신·네트워크 / 보안 솔루션. 공식 전시품목 분류를 묶은 것으로, 특별관 단위가 아니다
- 분야별 기록: 방문 부스(발표된 기업 칩 + 직접 추가 입력), 학교 적용가능성 상·중·하(선택), 교장용 질문 1개 메모
- 마무리 문항 3개(적용해보고 싶은 기술 1가지 이상, 교직원에게 한 문장, 1년 내 들어올 기술·이유) → 성명·소속교로 제출
- 같은 기기에서 다시 제출하면 시트의 기존 행을 덮어쓴다(제출ID 기준)
- 모든 입력은 기기(localStorage)에 즉시 저장되어 통신 두절·이탈 후에도 복구된다
- 제출 완료 화면에 집결 안내(14:50 D홀 출구, 15:00 버스 출발), 제출 후 하단 버튼은 「수정해서 다시 제출」
- 카카오톡 안에서 열면 기록 전에는 기본 브라우저로 자동 전환(`kakaotalk://web/openExternal`), 기록이 있으면 안내만 표시

## 아직 비어 있는 것 (배치도 공개 후 채운다)

2026-10-14 기준 공식 홈페이지에 2026 부스 배치도·참가기업 전체 목록이 공개되지 않았다. 앱은 다음 상태로 동작한다.

- 「추천 동선」: 배치도 미공개 안내문과 분야 목록만 나온다. `ROUTE`가 비어 있기 때문이다
- 「전시장 배치도 · 부스 찾기」: 배치도 대신 안내문과 공식 홈페이지 링크가 나온다. 부스 목록은 참가 발표 보도자료(2026-09-23, 10-12)에 나온 11개 기업만 들어 있고 부스 번호가 없다
- 부스 번호가 없으므로 분야 카드마다 「목록에 없는 부스 추가」 입력칸을 두었다. 공식 목록이 들어가면 `aifesta-mission`처럼 빼도 된다

배치도가 나오면 `index.html` `<script>` 상단에서 다음을 고친다.

1. `MAP.img`에 배치도 파일명(이 폴더에 넣는다), `MAP.alt`에 배치도 설명, `MAP.pending`은 빈 문자열. 브로슈어 PDF가 있으면 `MAP.brochure`·`brochureLabel`·`brochureNote`
2. `HALLS[].loc`에 분야별 위치 힌트, `HALLS[].b`를 `"D-01 기업명"` 형식의 공식 부스 목록으로 교체(부스 번호가 앞에 오면 목록에서 번호가 굵게 나온다)
3. `ROUTE`에 입구→출구 순서로 HALLS 순번(0부터)을 넣고, `ENTRY`·`EXIT`에 입구·출구 위치를 적는다
4. 특별관이 따로 생기면 `HALLS`에 항목을 추가한다. 다음 제출 때 시트 `현황` 탭이 자동으로 다시 만들어진다

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹앱 본체. 단일 파일, 외부 의존성 없음(시스템 폰트) |
| `Code.gs` | 제출 수신용 Google Apps Script. `aifesta-mission`의 것과 처리 방식이 같고 이름·기본 분야 목록만 다르다 |

## 배포

1. 구글 시트 「AIoT 참관미션 제출」을 새로 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다. AI FESTA 시트와 섞이지 않도록 별도 시트를 쓴다.
2. 편집기에서 `setup` 함수를 한 번 실행한다 → `제출`·`현황`·`명단` 탭 생성.
3. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**. 코드 수정 시에는 `배포 관리 → 편집 → 새 버전`(URL 유지).
4. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다. 지금은 비어 있어서 제출 버튼을 누르면 「제출 주소가 아직 연결되지 않았습니다」가 나온다.
5. 이 폴더를 별도 저장소(예: `aiot-mission`)로 옮기고 Vercel에서 Import(프레임워크 Other, 빌드 없음) → `aiot-mission.vercel.app`.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `INFO` — 연수명, 기수, 일자, 장소, 관람 시간, 집결 지점, 버스 시각
- `CONTACTS` — 인솔자·사무국 연락처. 안내 상자와 제출 완료 화면에 전화·링크 버튼으로 나온다
- `MAP` — 배치도 이미지, 브로슈어, 공식 홈페이지 링크, 미공개 안내문
- `HALLS` — 전시 분야. `z`는 카드 배지 코드, `loc`는 위치 힌트, `b`는 부스 칩 목록, `q`는 교장용 질문
- `ROUTE`·`ENTRY`·`EXIT`·`ROUTE_NOTE` — 추천 동선
- `FIELDS` — 시트 열 [키, 머리행 이름]
